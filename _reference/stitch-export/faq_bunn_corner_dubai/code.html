We proudly serve certified organic oat milk (calibrated specifically for micro-foam stretching), pure unsweetened almond milk, and smooth coconut milk.

We clean steam wands with dedicated color-coded cloths and run automated purge routines between all plant-based and dairy preparations to prevent allergen cross-contact.
